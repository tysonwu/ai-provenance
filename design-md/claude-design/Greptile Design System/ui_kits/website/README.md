# Greptile Marketing Website UI Kit

## Overview
High-fidelity recreation of the Greptile marketing website (greptile.com).

**Design width:** 1280px
**Background:** #EEEEEE with noise texture
**Fonts:** DM Sans (body), Anybody italic (display), Space Mono (labels)

## Components
- `Header.jsx` — Top navigation bar
- `Hero.jsx` — Hero section with headline + CTA
- `FeatureSection.jsx` — How it works, feature grids
- `Footer.jsx` — Footer with nav + logo

## Screens in index.html
1. Home page — hero, social proof, how it works, features
